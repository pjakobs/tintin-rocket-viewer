# Tintin Moon Rocket Viewer

A Three.js web viewer for the LEGO 21367 Tintin Moon Rocket, rendered from a pre-baked LDraw export.

## Language

**Rocket assembly**:
The 1,181-brick model actually shipped and rendered in the viewer — the official set inventory with loose minifig gear removed.
_Avoid_: Full model, the model

**Full inventory**:
The complete 1,255-brick official set contents, including the 74 loose minifig-gear pieces the viewer deliberately excludes.
_Avoid_: Box count, total pieces
